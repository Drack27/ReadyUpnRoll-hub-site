Project WhiteSpace

The game in your browser

  • Babylon.js: the 3D engine that draws the whole world
  • Havok Physics (@babylonjs/havok): collisions, jumping, falling over, and things that tumble
  • Colyseus client (@colyseus/sdk): keeps everyone's browser in sync with the host
  • node-qrcode: the invite QR codes

The host's computer

  • Node.js: runs the server, including its zlib (by Jean-loup Gailly & Mark Adler), worker threads, and single executable applications (how the .exe is made)
  • Colyseus, by Endel Dreyer and contributors (colyseus, @colyseus/schema, @colyseus/ws-transport): the multiplayer server
  • Express: serves the game and the uploads
  • ws and msgpackr: the live connections and the compact messages sent over them
  • cloudflared and Cloudflare's free Quick Tunnels: the invite link that works without router setup
  • Microsoft's .NET Framework, C# compiler and Windows Forms: the host's status window
  • Windows: what the host app runs on

Building it

  • Vite, with Rolldown, Oxc, Lightning CSS and PostCSS: packs the browser game together
  • esbuild, by Evan Wallace: squeezes the server into one file
  • postject: tucks it all inside the .exe
  • npm: fetches every package listed at the bottom of this page
  • Git, GitHub, GitHub Actions (checkout, setup-node, upload-artifact), GitHub Releases and the GitHub CLI: keep the code, build and test the .exe, and publish the downloads
  • Playwright and Chromium: the automated tests that play the game in a real browser
  • Python and Bash: little helper scripts along the way (including the one that wrote the package list on this page)

Testing it

  • Blender: for prepping 3D models for upload
  • CGTrader: for providing 3D models
  • A variety of sources of 2D images, for testing the upload and download of pictures, including Monte Cook's The Darkest House
  • The various manufacturers of my hardware, including but not limited to NVIDIA, AMD, Intel, Logitech, Blackview and more (I intend to flesh out this list more later)

The web, and the formats it reads

  • WebGL, WebAssembly, WebSockets, the Web Audio API (and AudioWorklet), WebCodecs and microphone access: the browser features that make 3D, physics and voice possible, and the people at the W3C, WHATWG and Khronos Group who wrote them down
  • Opus, from Xiph.Org and the IETF: the voice chat codec
  • Chrome, Edge, Firefox and Safari: the browsers it plays in
  • glTF / GLB (Khronos Group), Wavefront OBJ, and STL (3D Systems): the 3D model formats
  • PNG, JPEG, GIF (CompuServe) and WebP (Google): the picture formats, which WhiteSpace reads and writes with its own code, thanks to their published specs and DEFLATE (Phil Katz)

Inspiration

  • The Legend of Zelda: Ocarina of Time (Nintendo): the idea for Focus (F) comes from its targeting camera
  • Every tabletop RPG group that ever played over the internet and wished it felt more like sitting at the same table

This site

  • Plain HTML and CSS, nothing else
  • Cloudflare (Workers static assets and DNS): hosts it for free and forwards readyupandroll.com here
  • Inter, by Rasmus Andersson: the font, if your device has it (otherwise your system's own)
  • Your device's emoji (🎲 🔗 📅), drawn by its makers from the Unicode standard
  • GitHub: keeps this site's code
